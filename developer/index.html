GitHub Pages serves the web app and these downloads. It does not run Node or an MCP endpoint. The MCP server runs on your computer through an AI host supporting stdio. Planner writes require a separate authenticated team backend.

Using the app

Studio lets you browse brand products, collections and concept packs. Fitting Room contains BCPP Models, Clothing and Hair Style; styling entries link to their source concept packs. Production Plan organizes up to three looks per day, up to seven reference photos per look and up to two key products.

Plans on this static deployment are stored in your browser. Use the planner backup and restore controls to keep copies. Updating the site does not publish your plans or transfer them to the MCP server.

Export a shooting plan

Choose Export month PDF from the month calendar or a day plan, or choose Export this day for one date. Select Vietnamese or English and the current or landscape layout, then create the PDF. In browser-only mode, choose Save as PDF in the print dialog.

Every shooting day starts with a softly tinted Call sheet overview: crew and complete day notes on the left, stacked look rows with representative photos, names and selected key products/shades on the right. Shared notes appear only on this overview; look pages keep their own makeup and production briefs. A monthly or multi-date export adds full monthly calendars with look thumbnails at the front, followed by the day groups in date order. A daily export has its overview and looks, without a month calendar. Photos use the saved main reference and framing; a custom look without a photo keeps a labelled empty frame. Empty dates have no detail pages. Exporting does not modify your saved photos, framing, products, shades or notes.

Release boundaries

The MCP download contains public catalog JSON and runtime source, not private product spreadsheets, original photographs, account credentials or personal plans. Image references point to the web library; the archive does not duplicate the image library. Some styling slots remain unavailable because source evidence is missing.

Validation covers 75 responsive cases, planner regression tests and actual MCP client/server calls in an isolated test environment. Safari and physical mobile devices have not been certified.
